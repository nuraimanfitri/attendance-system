# Attendance System

A web-based attendance management system developed for tuition center staff operations and monitoring.

## Live Demo

https://www.pusattuisyenmathspower.my/attendance/index.php

## Features

* Staff authentication system
* Clock in / clock out functionality
* Push notification reminders
* Automatic clock out system
* Admin dashboard and monitoring
* Attendance tracking and reporting

## Tech Stack

* PHP
* MySQL
* JavaScript
* HTML/CSS
* OneSignal

## System Modules

* Staff Authentication
* Attendance Management
* Push Notification Service
* Admin Panel
* Auto Clock Out Scheduler

## Security Notes

Sensitive production credentials and API keys have been removed from this public repository for security purposes.
